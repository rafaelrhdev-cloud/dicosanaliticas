DICOSA — PUBLICAR EL SITIO Y LISTA DE SALIDA A PRODUCCIÓN
=========================================================

OPCIÓN A: SUBIR POR ARCHIVOS (la más simple)
  Hostinger > Administrador de archivos > public_html > subir el contenido del zip (ver LEEME-INSTALACION.txt).

OPCIÓN B: GIT + HOSTINGER (recomendada para actualizaciones)
  GitHub Pages NO sirve: no ejecuta PHP. Hostinger sí puede traer el código desde GitHub.
  1. Crea un repositorio PRIVADO en GitHub y sube el proyecto (el archivo .gitignore ya excluye data/ y las fotos).
  2. Hostinger hPanel > Avanzado > Git: agrega el repositorio, rama main, carpeta public_html.
  3. Activa el despliegue automático (webhook) para que cada cambio subido se publique solo.
  4. LA PRIMERA VEZ sube a mano por el Administrador de archivos la carpeta data/ con sus archivos base
     (site-data.json, branches.json, vacancies.json, credentials.php, mail-config.php). No se versionan a propósito.
  5. Nunca guardes en Git contraseñas ni datos de candidatos. Si se subieron por error, cámbialas.
